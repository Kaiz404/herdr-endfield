# Changelog

## Unreleased

### New

- **Archive squad and Close squad.** A squad header's right-click menu has two new items. **Archive squad** archives every chat in the squad's space, pinned ones included, the same way the session panel's **Archive** does, one at a time. It refuses to start while any agent is not idle and names each one. Each row shows its progress, and once every chat has ended the space closes. If one doesn't end, the space stays open and that chat stays in Squads. **Close squad** closes the space at once. Herdr ends every terminal in it, so the dialog names the agents it kills and offers **Archive squad instead**. **Pinned** has neither item. See [Archive or close a whole squad](docs/SETUP.md#archive-or-close-a-whole-squad).
- **Several Claude accounts.** Save Claude logins by name (a token from `claude setup-token`) and run each Claude Code agent on the one you choose. **Dispatch > New agent** has an **Account** box. The footer shows the focused agent's account: a saved name, or your email on the normal login. Click it or the limits to open **Account**, which moves a running chat to another account and keeps its history. It waits for the turn to end, or stops it with Esc if you choose **Stop now**. Then it ends the old agent and resumes the same session in a new tab. Tokens are encrypted with DPAPI on Windows and kept in the Keychain on macOS. They never pass through the skin. Pick a default account, and new agents from Dispatch and Herdr's menus start on it. See [Run agents on several Claude accounts](docs/SETUP.md#11-run-agents-on-several-claude-accounts).

- **Fold Spaces.** The Spaces header has a chevron, like a squad's. Click it to fold Spaces to its header, and Squads takes the freed height. The header, its count and its `+` stay. Click it again to unfold Spaces to the size it had. Endfield remembers the fold when Herdr restarts. The key command `endfield.toggleSpaces` does the same. See [Fold Spaces](docs/SETUP.md#9-choose-where-new-spaces-open).

### Changed

- **Resume says where a chat opens.** Each row in **Report > Archived** now says where **Resume** opens the chat. If the chat's space was closed, Resume opens a new space with the squad's old name instead of a tab in whichever space is shown, and the squad's other chats join it.
- **Squads rows say what runs, not who.** An agent's row now reads its program, such as `CLAUDE` or `CODEX`. A Claude Code sub-agent's row reads its type from Claude Code, with any plugin prefix dropped: `POTETO-AGENT` for `pstack:poteto-agent`, `GENERAL-PURPOSE`, `EXPLORE`, or `SUB-AGENT` when the transcript names none. The task line tells siblings of one type apart. A sub-agent gets a number (`EXPLORE-2`) only when two shown siblings share both type and task; pane agents are never numbered, since their task line changes with the tab name and title. The portrait is still the operator, and the operator's callsign, such as `PERLICA`, heads the session panel beside the label. The pane's name plate, the Report, the Finished slip, the Needs input cut-in, Dispatch and Comms name an agent the same way as its row. The model column no longer repeats the program for an agent with no Claude Code session.
- **Tighter Squads rows.** A row's name line and task line sit closer together, so each row reads as one unit, and the space between rows grows. Row heights are unchanged.
- **The earlier toggle sits between running and finished sub-agents.** Under an agent, the running and waiting sub-agents come first, then **+N earlier**, then (once opened) the finished ones. **Show less** stays right under the running ones, so folding never needs a scroll.
- **The session panel is a dossier.** Hover an agent or a sub-agent in Squads and its panel now opens on a header strip: the callsign, the kind and where it runs, then the task, then the status word and glyph with the model, effort and how long it has run. The Input, Generating and Tools cells and the Current formula are gone. Below the strip, in order: **Context**, a larger 20-block gauge with `211K / 1M` and the percent; **Tools**, the total calls and turns, then the four most used tools as bars with their counts; **Recent**, the last five tool calls, each with how long ago, the tool and what it worked on; then the background tasks and, for an agent, the chat actions. Sub-agents get the same layout, read from their own transcript. The panel still scrolls in a short window, and the buttons stay in view.
- **A calmer HUD footer, in three zones.** Left: how many agents work now, and a **Finished** button only while an agent finished a turn you have not seen (click: go to it). Middle: the focused agent's account, model, effort, branch and context. Right: the usage limits. The space and tab breadcrumb is gone (the sidebar and the tab bar show it), the separate Active and Generating counts are now one **Working** count, and the machine shows only when it is remote.
- **Usage limits follow the focused agent's account.** The HUD footer used to show the limits of whichever session reported last. Now it shows the limits of the focused agent's account, and its account in the middle of the footer. Copy the Claude Code statusline again: it now records the account (`"account"`) in each session file.

## 0.3.0

The run-the-fleet release. Squads now tell you how each run is going: its model and effort, how long it has run, its context, and whether it is waiting on background work. Agents are cast from all 36 operators by model tier. You can manage a chat from the skin: rename it, change its model, effort or mode, archive it and resume it later, and arrange squads by dragging. The HUD footer shows your Claude usage limits. Follow [docs/SETUP.md](docs/SETUP.md) to update. Two steps are new: copy the Claude Code statusline again, and fetch the bigger operator pack.

### New

- **Agents are cast by model, from the whole roster.** The operator catalogue grows from 8 to all 36 playable operators, each from the official site with its sha256. `node scripts/fetch-operators.mjs --accept` fetches the new ones (about 30 MB in all) and skips the ones you have. A stronger model draws a stronger operator: Fable draws from the top 6★ meta (Arcane, Argent Flow, Mi Fu and more), Opus from high-tier 6★ (Laevatain, Yvonne, Ardelia and more), Sonnet from mid-tier 5★, and Haiku from the 4★ operators. GPT, Gemini, Grok, Cursor Composer, DeepSeek, Kimi, Qwen, GLM, MiniMax, Mistral and small local models map to the same four tiers. Claude Code sub-agents draw different operators from each other, so five Sonnet sub-agents are five different operators, not `ARDELIA-2` to `ARDELIA-5`. A callsign gets a number only when every operator in the pool is taken. Every agent keeps its operator when another agent closes or another agent's model arrives. Only a change to its own model tier draws it again. A model the skin does not recognise draws the Endministrator. See [Casting](docs/CASTING.md).
- **Waiting.** A Claude Code agent whose turn ended while a background shell, agent, monitor or sub-agent it started still runs used to read **Idle** or **Finished**. A sub-agent in a long wait used to read **Finished** after 20 seconds without output, and Squads hid it. Both now read **Waiting**, with two still bars, in Squads, the pane's name plate, the Report and the session panel. A waiting sub-agent stays under its parent like a Generating one. A waiting agent does not count as Finished in the HUD footer. Squads reads this from the transcript and from whether the session's Claude Code process still runs, not from how long ago the agent wrote. Typed actions and Dispatch still follow Herdr's own status, so you can still type into a waiting agent that Herdr calls idle. The Finished slip still appears when Herdr reports the turn done.
- **Background tasks.** When a Claude Code agent has started background work, the session panel gets a **Tasks** section, like the Claude desktop app's background task list. Each running task shows a glyph for its kind (a prompt for a shell, a figure for an agent, a pulse for a monitor), its description and how long it has run (`42s`, `27m`, `1h07`), newest first. The tasks that have ended fold under **+N finished**. Unfold them to see each one's end (`done`, `failed`, `killed`, `stopped`, `timed out`, or `ended` when its session closed) and how long it ran. The tasks of the agent's sub-agents are included. A long list scrolls inside the panel, and the buttons stay in view. In Squads, an agent or sub-agent with tasks running shows a small stack glyph and their count left of its clock. Hover it for the words.
- **Chat actions in the session panel.** A new **Chat** row shows the agent's model, effort and mode, and has one button per action: Rename, Plan, Next mode, Model, Effort and Archive for Claude Code; Rename, Model and Archive for Codex; Rename, Plan and Archive for Cursor. Each button opens a dialog that shows the exact `hc` command, what it needs and what it changes, and runs it only when you click **Confirm**. Anything typed into the agent goes with `hc send --if idle`, so a working, blocked or finished agent is never typed into. The button says why it is dimmed. `/model` and `/effort` also become your Claude Code defaults, and the dialog says so. Afterwards the dialog shows the new model, effort or mode when the skin can read it. See [Change a chat](docs/SETUP.md#change-a-chat-from-its-session-panel).
- **Right-click keeps the session panel open.** Hovering an agent in Squads shows its session panel, and the panel closes when the pointer leaves. Right-click the agent to keep its panel open while you read it or use its buttons: Rename, Pin, Archive and the other chat actions are all in the panel. It closes when you click outside it or press Esc. There is no separate right-click menu for an agent.
- **A session panel for sub-agents.** A Claude Code sub-agent's row in Squads now has a panel too, on hover and on right-click. It shows the sub-agent's status (Generating, Waiting or Finished), its model and effort, how long it has run, its context, its last action and its background tasks. **Open transcript** opens its transcript pane. **Follow-up** opens the same pane with the follow-up box ready to type in. The follow-up goes through its parent, as before. A sub-agent is not a terminal, so its panel has no Rename, Pin or Archive.
- **Archive and Resume.** **Archive** ends a chat with `/exit` (`/quit` for Codex and Cursor), keeps its transcript, takes it out of Squads and records it. **Report > Archived** lists those chats. **Resume** opens a new tab in the chat's folder running `claude --resume <session id>`. See [Archive a chat and resume it](docs/SETUP.md#archive-a-chat-and-resume-it).
- **Arrange squads and chats.** Drag a squad's header in Squads to reorder the squads. The squad lifts and follows the pointer, and the other squads slide aside to open a gap where it lands. Esc, or moving the pointer out of the list, cancels and slides them back. In **Tab order**, drag a chat the same way to reorder it within its squad (`tab.move`), and its sub-agents move with it. In **Priority** order, chats don't drag. Double-click a squad's name to rename the squad in place, and press Enter to save. Right-click a header for **Rename squad**, **Move up** and **Move down**. A squad is a Herdr space, so the new order and name are Herdr's (`space.move`, `space.rename`) and the Spaces list shows them too. Squads can't move a chat to another squad, because Herdr has no command that moves a tab to another space. See [Arrange squads](docs/SETUP.md#arrange-squads-and-chats-in-squads).
- **Follow up with a sub-agent.** The transcript pane of a Claude Code sub-agent has a box at its foot. Type a follow-up and click **Send** or press Enter. A Claude Code sub-agent has no terminal to type into, so the box sends your text to its parent agent and asks the parent to pass it on with its SendMessage tool. The pane says so (**Sent via PERLICA**) and shows the exact `hc send` command before you send. It sends only when the parent is waiting for you (idle or finished). While the parent is working or needs input, **Send** is disabled and the pane says why. Each follow-up appears in Comms. Agents started with `hc` have their own terminal, so you type in their pane or use Dispatch, as before.
- **Usage limits in the HUD footer.** The footer shows your Claude 5-hour and weekly limits, each as two short rows: the percent used on top (`5-HOUR 54% USED`), a small bar and the time to reset below (`RESETS 1H 40M`). From 80% a window turns red with a `▲`. A window that has reset since Claude Code last reported it reads `RESET` over an empty bar, not its old numbers. In a narrow window the bars go first, then the weekly window's `USED`. The numbers come from the Claude Code statusline. Without it the section is not shown.
- **Home base.** New spaces on this computer open in a workspace folder instead of your home folder, so an agent you start there treats that folder as its project, not your whole home folder. The default is `Projects` in your home folder if it exists. Set `homeBase` in `data/endfield/settings.json` to choose another folder. If that folder is missing, spaces open in your home folder and the sidebar says so. Spaces on other machines still open in that machine's home. The Spaces header shows the base, and the key command `endfield.newSpace` opens a space there. See [Home base](docs/SETUP.md#9-choose-where-new-spaces-open).

### Changed

- **Copy the Claude Code statusline again.** The [statusline](extras/claude-statusline/README.md) now also records your usage limits (`rate_limits`) and the effort level. The HUD footer's usage limits need them, and the session panel shows a changed effort at once. The installer does not touch `~/.claude/`, so copy `statusline-endfield.sh` there again. See [Update the statusline](docs/SETUP.md#update-the-statusline).
- **Squads rows say how a run is going.** Each agent and each Claude Code sub-agent keeps two lines. The first line has the callsign, the model, and the effort level in a dimmer grey, for example `OPUS 5.5  MED`. At its right are a clock with how long the run has gone, then the status: `◷ 43m  ▶▶ Generating`. A run under a minute counts seconds (`42s`), then `27m`, `1h07`, `12h` and `3d`. The second line has the task, with an 8-block context gauge at its right that runs red past 75%. Hover the gauge for the numbers, such as `157K / 1M, 16%`. The time since the last state change, the terminal address (`T3H`) and the tool count are gone from the row. The session panel still shows the tool count. An idle agent's row folds to one line with its callsign, task and **Idle**, so the agents that are working get the room.
- **Claude Code sub-agents.** Squads used to show at most four sub-agents under a parent, picked in no useful order. Now it shows every working or waiting sub-agent, newest first. A row under them, **+N earlier**, lists the finished ones too, newest first. **Show less** folds them away again. Each parent remembers its choice until Herdr reloads the skin. A long list scrolls.
- **One motion per working agent.** A generating row in Squads no longer has a blue segment sliding along its floor. The status glyph still animates, so a sidebar full of working agents is calmer.
- **One transcript pane per tab.** Clicking a Claude Code sub-agent in Squads opens its transcript right of its parent, as before. Clicking another sub-agent now replaces that pane instead of splitting the tab again, and clicking the one shown focuses it. The shown sub-agent's row is marked as selected.
- **The transcript pane is part of the `endfield` mod.** It used to be a separate mod, `endfield-transcript`, with its own copies of the Dispatch rules. `install.mjs`, `sync.mjs` and `uninstall.mjs` remove the old `mods/endfield-transcript` folder. A transcript pane left open from before the update can show an error. Click a sub-agent in Squads to replace it, or close it.
- **The session panel shows context once.** The **Output** number, which counted every token the session ever processed, is gone. **Context** shows the input tokens of the last request, which is what the session carries now, with its 20-block gauge. The panel's chip names the tab (or the space) instead of the terminal address, and the third cell counts tool calls.
- **Claimed is now Finished.** The status word for an agent that finished its turn reads **Finished** in Squads, the Report, the HUD footer (`01 FINISHED`) and the slip a finished agent gets. The status words are now Generating, Waiting, Needs input, Finished, Idle and Error. The sound file keeps its name, `claimed.mp3`, so a `sounds.done` setting that points at it still works.
- **No dots between data.** Labels that used to run pieces together with `·` now set them apart with a gap, and the secondary pieces in a dimmer grey: the HUD footer (`CTX` `FOCUSED`, then model, branch and machine), the brand line, the session card, the pane plate, Spaces, Report, Comms, Dispatch, the toast, the cut-in and the boot screen. Tooltips use commas, and a transcript's tool line reads `● Tool arg`. A numbered callsign reads `PERLICA-2`. `verify.mjs --static` now fails on a `·` or `•` in skin code outside comments.
- **Dispatch's Only if idle and finished agents.** With **Only if idle**, a target that finished its turn used to read "Idle. Delivered now.", and then hc refused the send. A finished agent waits at its prompt, so it now gets a plain send, and the preview says it finished its turn. While the target is generating or stopped on an error, **Only if idle** now disables **Dispatch** and says why, instead of letting hc refuse. The sub-agent follow-up box uses the same rule.
- **Operator overrides start empty.** `data/endfield/operators.json` used to be seeded with one operator per program, which would hide casting by model. The seed is now empty. `node scripts/install.mjs` replaces your copy if you never edited it, and keeps it if you did. Your own `programs` and `terminals` entries still win over the model. With no known model, Codex now defaults to Laevatain instead of the Endministrator.

### Fixed

- **Operators come back after a failed reread.** If one reread of the art pack or `operators.json` failed, every agent stayed drawn as its program (`CLAUDE CODE`, `CLAUDE CODE-2`) until the skin reloaded, and editing `operators.json` changed nothing. The next reread now runs as usual.
- **The session panel no longer stays open after you move on.** It closes when you click anywhere outside it, such as on Files, Comms or Report, and when you fold the sidebar. Clicking the agent's own row keeps its panel. One case is not fixed: if the pointer leaves the row or the panel and Herdr does not report it, the panel stays until your next click.
- **The session panel fits the window you have.** In a short window, the panel's middle (the machine panel, Context, Tasks and Chat) could shrink to a sliver between the head and the footer. The panel also measured the window without your zoom, so it was cut short when zoomed out and could run past the window's foot when zoomed in. It now measures the window at your zoom each time it opens, and places itself again when the window or the zoom changes while it is open. The middle keeps at least 120px and scrolls.

## 0.2.0

The game-UI release. Agents are now drawn as Arknights: Endfield operators in squads, and you can send them work from the skin. Follow [docs/SETUP.md](docs/SETUP.md) to install or update.

### New

- **Squads.** The sidebar groups agents by space, one numbered squad per space. Each agent is a party chip: the operator's round portrait, a yellow ring when it needs input, and a badge for its program (`C` Claude Code, `X` Codex, `Cu` Cursor, `O` OpenCode, `G` Gemini). Each has a callsign such as `PERLICA` over its task. Sub-agents hang under their parent, whatever program they run. Click a squad header to fold it to a stack of portraits. Status words follow the game: Generating, Needs input, Claimed and Idle.
- **Operator portraits on screen.** With the art pack, the portraits show in the sidebar, the pane name plates, the session panel, Dispatch, Comms, the Report and the needs-input cut-in. Without it, every surface shows the program's tile, as before.
- **Many agents.** From 12 agents the sidebar goes compact, spaces become numbered squares, and agents that need input are pinned above every squad. The list scrolls and says how many agents are below.
- **Needs-input cut-in.** When an agent needs you and you are looking elsewhere, a banner shows its portrait, its callsign, the question from its screen, and **Answer** and **Later**. If its pane already has focus, the pane's name plate flashes yellow instead. A finished agent gets a short **Claimed** slip.
- **Session panel.** Hover an agent to see its bust portrait, folder, model, state, elapsed time, turn, tokens, context, recent messages and its last action, with Peek, Pin, Dispatch and Answer.
- **Report.** The **Report** pill opens one screen with every squad: totals, then one row per agent with output over the last 10 minutes, token rate, context, turn and status. Click a column heading to sort.
- **Dispatch.** Send a task to a running agent, or start a new agent in a squad, from a dialog. The dialog shows the exact `hc` command before you click **Dispatch**. It runs that command once, and only when you click.
- **Comms.** The **Comms** pill opens a pane with what you dispatched and the messages agents sent each other through `hc`. Messages read from an agent's screen are marked Unverified.
- **Name-plate pane headers, HUD footer and boot.** Pane headers carry the program tile, the operator chip and the title in wide capitals. The status bar is a 44px HUD with live counts and a **Needs input** block. Herdr starts with a short type-on screen.
- **Original sounds.** A needs-input alert, a Claimed chime and quiet clicks, made for the skin. They never play on top of Herdr's own sounds.
- **Setup guide.** [docs/SETUP.md](docs/SETUP.md) goes from a fresh machine to the full setup, with checks, undo steps and troubleshooting.
- **Demo fleet.** `node scripts/demo-fleet.mjs up --agents 30` fills Herdr with stand-in agents to try the layout. `down` removes them.
- **Tests.** The roster, Dispatch and Comms rules run under `node --test`, in CI and in `verify.mjs`.

### Changed

- **One mod.** Notifications are now part of the `endfield` mod. The installer removes the old `mods/endfield-toast` folder.
- **Calmer motion.** A selection's plate and text change in one frame, and only the yellow marker slides. Idle agents and an idle fleet draw nothing that moves.
- **The art pack has six files per operator.** The new `bust-480.png` is the session panel's portrait. If you fetched the pack before, run `node scripts/fetch-operators.mjs --accept` again to add it.

### Fixed

- Sub-agent callsigns stay small. A long Claude Code session showed `ARDELIA·30`. Each sub-agent now takes the lowest number that no other shown sub-agent holds, and keeps it while it is shown.
- A pack fetched with `fetch-operators.mjs` showed no bust in the session panel.
- A Dispatch order that `hc` accepted is never sent twice.
- A callsign never moves from one agent to another when agents come and go.

## 0.1.0

First publication. Not tagged.

### New

- **First public layout.** The Endfield layout, its light and night themes, the `endfield`, `endfield-toast` and `endfield-transcript` mods, and a settings preview.
- **Install and uninstall scripts.** `node scripts/install.mjs` copies the skin into your Herdr home, backs up any Endfield file it replaces, and is safe to rerun. `node scripts/uninstall.mjs` removes it and restores the backups.
- **Opt-in extras.** A Claude Code statusline that also feeds the skin exact session data, and a PowerShell prompt.
- **Bring-your-own art pack.** `art-pack/build_pack.py` turns your own images into operator avatars and a manifest.
- **Official operator art, fetched on your machine.** `node scripts/fetch-operators.mjs --accept` downloads eight official operator renders, checks each against a pinned sha256, and builds the art pack into your Herdr home. The repo itself contains only the catalogue (`art-pack/operators.json`): URLs, hashes and crop settings.
- **Checks.** `node scripts/verify.mjs` checks the mods against a running Herdr. `--static` runs in CI and also rejects official art and personal data.
